# Model card

## Model details

- **Project:** Breast Cancer Classification Challenge
- **Task:** Binary classification of malignant and benign observations
- **Positive class:** Malignant
- **Dataset:** Breast Cancer Wisconsin Diagnostic dataset distributed with scikit-learn
- **Final model:** Generated by the notebook after cross-validated comparison

## Intended use

This model is intended only for teaching supervised machine learning, validation, evaluation, interpretation, and reproducibility.

## Excluded uses

The model must not be used to diagnose patients, recommend treatment, replace clinical judgment, or support a real medical decision.

## Evaluation

The notebook reports cross-validation results on the training partition and a final evaluation on a fixed stratified test partition. It includes sensitivity, specificity, precision, F1, ROC AUC, average precision, Brier score, and confusion matrix values.

### Validated reference execution

The project was executed end to end with the declared random seed. Logistic regression was selected by five-fold cross-validated ROC AUC and produced the following held-out results:

| Measure | Value |
| --- | ---: |
| Accuracy | 0.9737 |
| Sensitivity | 0.9524 |
| Specificity | 0.9861 |
| Precision | 0.9756 |
| F1 | 0.9639 |
| ROC AUC | 0.9954 |
| Average precision | 0.9931 |
| Brier score | 0.0222 |
| False negatives | 2 |
| False positives | 1 |

These values describe one benchmark split and are not evidence of clinical validity.

## Limitations

- The dataset is small and may not represent current populations or clinical practice.
- The observations do not establish performance across institutions, devices, or demographic groups.
- A random split does not test geographic, temporal, or institutional transportability.
- Good benchmark performance does not demonstrate clinical safety or effectiveness.

## Required review before any real deployment

Clinical oversight, representative data, external and prospective validation, privacy and security controls, subgroup analysis, regulatory review, monitoring, and human decision authority would all be required.
